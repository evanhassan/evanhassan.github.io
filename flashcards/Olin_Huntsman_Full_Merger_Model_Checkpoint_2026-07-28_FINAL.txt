8. OLIN SHARE / EQUITY SCHEDULE — UPDATED MECHANICS
======================================================================

The equity schedule is the sole source of share counts.

Core share flow:
Beginning Common Shares
+ Net Shares Issued / (Repurchased)
= Ending Common Shares

Weighted-Average Common Shares:
- Simplified formula = AVERAGE(Beginning Common Shares, Ending Common Shares)
- This assumes the net share movement occurs halfway through the year

Dilutive Effect:
- Historical Dilutive Effect = Mergent Diluted Weighted-Average Shares - Mergent Basic Weighted-Average Shares
- Forecast Dilutive Effect is a blue driver
- The latest intended visible assumption was approximately 2.0mm per year
- The most recent uploaded workbook snapshot still showed 1.5mm; confirm the final workbook value
- Do not subtract Stock-Based Compensation expense from diluted shares; dollars and shares are different units

Weighted-Average Diluted Shares:
= Weighted-Average Common Shares + Dilutive Effect

Standalone EPS denominator:
- Olin Standalone must link to Weighted-Average Diluted Shares
- Do not link EPS to Ending Common Shares

Forecast basic-share assumptions:
- 2026E net shares issued: +0.6mm
- 2027E-2031E net shares issued: +0.5mm annually

Dividend assumption:
- $0.80 per share annually

Stock-Based Compensation:
- approximately $20mm annually

Common Stock:
- Olin par value = $1 per share
- New issuance increases Common Stock by newly issued shares x $1 par value
- Do not increase Common Stock by market value

APIC:
- Total stock-compensation equity credit must be split between Common Stock and APIC
- Example: $20mm SBC and 0.6mm newly issued shares at $1 par
  - Common Stock increase = $0.6mm
  - APIC increase = $19.4mm
- Do not credit the full $20mm to APIC and also credit $0.6mm to Common Stock; that double counts equity

Share-accounting toggles:
Positive Share Toggle:
- 1 = newly issued shares
- 0 = treasury shares reissued

Negative Share Treatment:
- 1 = shares repurchased and retired
- 0 = shares repurchased and held in treasury

Par Value Per Share:
- $1 for Olin

Positive share treatment:
- New issuance changes Common Stock and APIC
- Treasury-share reissuance generally changes Treasury Stock and APIC, not Common Stock

Negative share treatment:
- Retirement reduces Common Stock by par value and routes remaining cost through APIC / retained earnings
- Treasury treatment makes Treasury Stock more negative and leaves Common Stock unchanged

Important limitation:
- Exact treasury-share reissuance accounting requires the original treasury-stock cost basis
- Mergent does not provide that cost basis
- The template may use a simplified convention or an additional cost-basis assumption
- Do not pretend share count alone can calculate Treasury Stock dollars

Historical Stock Issuance / (Repurchases):
- The CFS row is a dollar cash-flow amount
- It is not the same as the net share-count movement

Assumption rows for Common Stock and Treasury Stock:
- These should be deleted or ignored once the outputs are formula-driven
- Common Stock and Treasury Stock should be schedule outputs, not independent forecast assumptions

10. EXISTING CASH USED — CORRECT PLUG LOGIC
======================================================================

Existing Cash Used may plug the remaining real cash funding need, but it must be bounded.

Conceptual formula:
Existing Cash Used =
MAX(0,
    Total Uses
    - Value of Shares Issued
    - New Debt Issued
    - Other Sources)

Do not allow Existing Cash Used to become negative.

A negative cash-used result means:
- the deal is overfunded;
- too much new debt was issued;
- a refinancing / repayment use is missing; or
- another legitimate use has not been modeled.

Optional diagnostic row:
- Excess Cash / Debt Paydown
- Use only if excess financing is intentional
- Do not use it to hide a missing refinancing use

For the current base case:
- New Senior Notes of $1,150mm are an inactive scenario assumption
- With Debt Financing Switch = 0, New Debt Issued = 0
- Existing Cash Used = $73mm

11. REPAYMENT VS REFINANCING VS RESTRUCTURING
======================================================================

Repaid, not refinanced:
- Old debt repayment = Use
- New debt issuance = 0
- Net debt declines

Refinanced:
- Old debt repayment = Use
- Replacement debt issuance = Source
- Net principal may be unchanged
- Old and new instruments remain separate gross transactions

Restructured / amended without full extinguishment:
- Existing debt may remain outstanding
- Rate, maturity, covenants, collateral, or amortization may change
- Sources & Uses should include only actual cash repayment, new issuance, and fees
- Do not automatically show full principal as both a use and source

Current template convention:
- Refinance / Repay at Close? = 1 means the old tranche is extinguished at close
- Replacement financing, if any, comes through the New Debt Issued table
- True amendment accounting is outside the current automated macro and should be handled deliberately if needed

Either target or acquirer debt may be repaid / refinanced.
The correct treatment depends on transaction documents and the intended capital structure, not merely whether the legal form is called a merger or acquisition.

12. SOURCES & USES VBA — FINAL INTENDED ARCHITECTURE
======================================================================

Final macro file:
- RefreshSourcesUses_InsertRows.bas

Button location:
- Sources & Uses tab

Button assignment:
- RefreshSourcesUses

The button refreshes three blocks:
1. Target Debt Repaid / Refinanced at Close
2. Acquirer Debt Repaid / Refinanced at Close
3. New Debt Issued

The macro inserts and deletes detail rows dynamically.
The user decided row growth is acceptable because the sheet can be zoomed out.

Target / acquirer debt logic:
- Reads Target Company Name and Acquirer Company Name from Transaction Assumptions
- Finds each company's debt schedule dynamically using the company name plus "Debt"
- Finds the debt table using required headers, not a hardcoded table name
- Required columns:
  - Debt Instrument
  - Refinance At Close? or an accepted close-treatment header variant
- Finds the transaction close year from Transaction Date
- Finds each instrument's closing-year Ending Balance in the debt buildout
- Creates a live formula:
  Closing-Year Ending Balance
  x Refinance / Repay at Close toggle
  x global Debt Financing Switch
- Inserts one detail row per debt instrument
- Sums the parent subtotal

New debt logic:
- Finds the New Debt Issued financing table on Main Page & Assumptions
- Reads each nonzero instrument
- Prints only:
  - Debt instrument name
  - Amount
- Does not print the rate in Sources & Uses
- Each amount is multiplied by the global Debt Financing Switch
- Parent New Debt Issued row sums the generated detail

Reusability:
- The macro should work with names such as Huntsman Debt, Olin Debt, or Google Debt Schedule
- It should not require editing a hardcoded DEBT_SHEET constant for every transaction
- It relies on stable labels and table headers

When to click Refresh:
- After adding a debt instrument
- After deleting a debt instrument
- After renaming a debt instrument
- After materially changing table structure

When no refresh is required:
- Changing a debt amount
- Changing a 0 / 1 close toggle
- Changing the global Debt Financing Switch
- Existing generated rows contain live formulas and should update automatically

Important:
- Save the workbook before running a macro because macro changes generally cannot be undone
- Do not place persistent manual formulas inside generated detail rows
