How it works:
1. Select Model Builder / coding blocks from Mode.
2. Choose a schedule.
3. Drag rows into workbook order, or use the arrow buttons.
4. Check the order.
5. Complete the mechanics and linkage quiz for the block.
6. Continue through the schedule.

The app is self-contained. Existing flashcard IDs and prior builder IDs were preserved, so prior exported progress remains compatible. Progress exports include flashcard scheduling data and Model Builder completion data.
